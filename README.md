# Mirchi Restaurant Website - Project Roadmap

This project is a high-end, animated restaurant website built with Vue 3 (Vite).

## 🗺️ Project Roadmap

### Phase 1: Foundation Setup ✅
- [x] Project Initialization
- [x] Folder Structure Organization
- [x] Routing Configuration (`MainLayout`, `front_routes`)
- [x] Global CSS (Dark Premium Theme) & Component Registration

### Phase 2: Home Page (In Progress) 🚧
- [x] **Design Refresh**: Implemented "Dark Premium" theme with Gold/Red accents.
- [x] **Hero Section**: Full-screen parallax background with animated typography.
- [ ] **Features Section**: Highlight Key Selling Points (Fresh, fast, halal).
- [ ] **Popular Menu**: Grid/Slider of top dishes.
- [ ] **Testimonials & Newsletter**.

### Phase 3: Menu Page
- Sidebar/Top Bar Categories.
- Search Functionality.
- Product Cards with "Add to Cart".
- Modal for dish details.

### Phase 4: Cart & Ordering System
- Pinia State Management.
- Slide-over Cart Widget.
- Checkout Page (Order Summary, Delivery/Pickup, Payment).

### Phase 5: Reservation System
- Table Booking Form (Date, Time, Party Size).

### Phase 6: Contact & About
- Contact Info & Map.
- Chef's Bio & Gallery.

### Phase 7: Polish & Optimization
- Advanced Animations (Scroll reveal).
- SEO & Performance Tuning.
- Mobile Responsiveness Polish.

## 🛠️ Tech Stack
- **Framework**: Vue 3 (Composition API)
- **Build Tool**: Vite
- **Styling**: Vanilla CSS (Custom Utility Variables) + Dark Theme
- **State**: Pinia (Planned)
- **Animations**: Custom Plugins (`src/plugins/animations.js`)
